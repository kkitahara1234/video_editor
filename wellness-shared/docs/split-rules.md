# 分割ルール（split-rules）

> 対象: ショート動画のテロップ分割実装仕様

最終更新: 2026-06-04

analyze-step2-v2.ts が読み込む split-rules.json と同期する人間向け仕様書。
コード変更前にこのドキュメントを更新し、続いて split-rules.json を更新する。

## 基本制約
- TELOP_MAX_CHARS: 12字以内
- EMPHASIS_MAX: 1ショートあたり強調語7個まで
- SPACE_MIN_LEN: 半角スペース分割の最小長 2字

## 分割禁止: テロップ先頭禁止語 (DO_NOT_START_WITH)

テロップの先頭がこれらで始まる場合、分割位置として無効。前テロップに統合する。

## 分割禁止: 直前+直後の組み合わせ (DO_NOT_SPLIT_BETWEEN)

| 直前 | 直後で始まる | 説明 |
|---|---|---|
| と | いう/いっ | 「という」「といって」 |
| に | なっ/なる | 「になって」「になる」 |
| も | の | 「もの」分断回避 |
| こ | と | 「こと」分断回避 |
| もの | に/を/が/で | 形式名詞+助詞 |
| こと | に/を/が | 形式名詞+助詞 |
| ものにな | っ/り/る | 「ものになって」等 |
| ことにな | っ/り/る | 「ことになって」等 |
| させて/やらせて/らせて/せて | いただ | 補助動詞「いただく」 |
| て | いる/います/いて/いた/いない/いません | 継続体「ている」 |
| みた | い | 「みたい」 |
| みたい | な | 「みたいな」 |
| るん | です/で | 「るんです」 |
| が | ち | 「がち」 |
| は | ず | 「はず」 |
| はず | です/だ/で | 「はずです」等 |
| ら | れる/れた/れて/れない/れます | 「られる」活用 |
| るん | ですけ/ですけど/ですけれども | 「るんですけど」等 |
| ているん | です/で | 「ているんです」 |

## 複合動詞分断回避 (COMPOUND_VERB_STARTS)
splitPos 以降が以下で始まる場合は分割禁止（正規表現）:
`^(らせて|られ|させて|せて|れて|れる|れた|れない|いただ|ただ)`

## 数字+単位保護 (NUM_UNIT_PATTERN)
数字の直後に以下の単位が来る場合は分割禁止:
`^(万|億|円|%|％|年|ヶ月|月|日|時間|分|秒|個|名|人|件|度|回|台)`
「万円」「億円」の連結も保護。

## 行頭禁止 (LINE_START_PROHIBITED)
splitPos 以降が以下で始まる場合は分割禁止:
- 促音: っ、ッ
- 拗音: ゃ、ゅ、ょ、ャ、ュ、ョ
- 長音: ー
- 小文字: ぁ、ぃ、ぅ、ぇ、ぉ、ァ、ィ、ゥ、ェ、ォ

## 句読点・記号除去
removePunctuation で以下を除去:
「、」「。」「,」「.」「，」「．」「？」「！」「?」「!」

## 半角スペース強制分割
xlsx 元データの半角スペースを文区切りとして分割。
両側 SPACE_MIN_LEN (2字) 未満なら分割しない。

## proper-noun 終端ボーナス
分割候補で proper-noun の終端と一致する位置は距離x0.5 で優先。

## 12字超過 proper-noun の独立抽出
proper-noun が 12字超過の場合、1テロップとして独立（12字制限の例外）。

## 隣接テロップ統合 (merge)
DO_NOT_SPLIT_BETWEEN / DO_NOT_START_WITH に該当する隣接テロップは統合。
統合後 12字超過なら autoSplit12chars で再分割。

## 短いテロップ統合 (mergeShortTelops)
3字以下のテロップを前後と統合（proper-noun は除く）:
- 前テロップに統合（基本）
- 前がない or 統合後12字超過の場合は次と統合
- 2-3パスで連鎖統合に対応

## バランスペナルティ
両端が4字未満の分割位置に effectiveDistance +100 のペナルティ。
強制ブロックではなくスコアリング。proper-noun 終端は例外。
merge ループに MAX_MERGE_OPS=50 の安全弁。
