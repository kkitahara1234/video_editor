# 対談動画 制作フロー(mic単独認識を土台にする版)

## 根本方針
master.wav(ミックス)のwhisperX認識は、word時刻圧縮・話者誤認・息継ぎ誤区切りが起きる。
これを土台にすると、出来上がりから壊れを1個ずつ検出して直す無限ループになる。
**最初の文字起こし段階で話者ごとにmic単独認識する。** 修正箇所が激減する。

## 推奨フロー(新規対談)
1. **話者別mic単独認識(土台)**
   - 中田=mic_a、林=mic_b を、各話者の実発話区間だけ切り出してwhisperX認識
   - 無音を長く含めるとalignment崩壊(文字を引き伸ばす)→実発話区間だけ短く(5秒前後、話者交代をまたがない)
   - 各マイク=本人の声だけ→話者誤認ゼロ。ただしword時刻は2-4倍圧縮されるため時刻決定には使わない(thelongevity_3で実証: cps23-35の圧縮多発)
   - テキスト・話者の土台としてのみ使う。時刻は音量ベースで別途決定
2. **検出で変なところを確認(土台が正しいか全編チェック)**
   - detect_compressed.py: mic音量で実発話ブロック検出→テロップ表示時間と比較、充足率<70%=圧縮疑い
   - cps>13も候補。テロップ間隙間0<gap<0.1s=点滅候補
   - カメラ: angle vs 実話者(mic複数点+master多数決)で照合
3. **個別対応(検出で出た箇所だけ)**
   - 下記「罠と原因の対応表」を見ながら直す
4. **隙間ゼロ化**: 連続発話区間のテロップ間微小隙間(0<gap<0.1s)をend=次startで点滅解消
5. **Studio確認 → render → 完成**

## 時刻データの優先順位(thelongevity_3で確立)
1. **北原さん目視秒** — 動画再生しながら「この秒で切り替わる」を確認。最も正確
2. **音量timeline** — mic_a/mic_bの0.3s刻みRMS音量で「誰がいつ話しているか」を判定。機械的に全編一括測定可能
3. **認識word時刻** — whisperXのword alignment。**時刻決定には使わない**(2-4倍圧縮が常態)。テキスト照合のみに利用

## 音量timeline作成・テロップ照合
1. **全編一括音量測定**(1回、約30秒)
   ```bash
   # ffmpeg astats でmic_a/mic_bの0.3s毎RMSを取得→work/volume_timeline.json保存
   ```
2. **各テロップの「話者が話してるか」照合**
   - start時に話者が話してない → ずれ
   - 表示中の話者発話割合<40% → 話者ずれ or 間延び
   - cps>18 → 詰まり、cps<3.5かつdur>2.5 → 間延び
3. **問題箇所を北原さん目視秒で確定**

## テロップ時刻調整手順
- **スプシが正**(最新xlsxのテキスト列・話者列が絶対)
- 差分のみ反映(全件再計算しない)
- 語移動ペア(隣接テロップ間で単語移動)は北原さんが記入した修正時刻列をそのまま使う(文字数比配分しない)
- end=次テロップのstartで隙間ゼロ化
- 保護区間(北原手修正済み)は触らない
- JSONのsubtitles配列を直接操作(ローカルリスト変更ではJSON反映されないバグに注意)

## スプシ(xlsx)運用
- 列構成: No/開始/終了/話者/話者修正/テキスト/文字数/テキスト修正/cps/画角/修正時刻/備考
- 北原さんが行挿入した場合: テキスト列を直接編集(修正列ではない)。JSONに件数差が出る→挿入・削除を正確に特定してから反映
- _line(2段テロップ)データが通常テロップと重複表示される場合あり→不要な_lineは削除

## カメラ
- prepare.ts CAM_STEP_SEC=6 で6秒固定segmentになる→6秒内の話者交代に追従できない
- recut_camera.py: mic 0.5s粒度で話者判定、最低カット長2秒(短い相槌は吸収しチカチカ防止)
- **front画角**: 20秒周期で10秒間frontを挿入(中田連続発話区間の単調さ回避)。掛け合い(cam_b/林区間)には食い込まない。テロップ境界に合わせて切る

## 重要前提
- mic_a/mic_b/master.wav は同一タイムライン(カット割同じ)。micの時刻=動画時刻として有効(検証済み)
- GlobalTelopLayerは Object.values(subtitles).flat() でseg.id非依存(改修済み)→segment再カットでテロップ消えない
